# Upstream

`src/core` is vendored from [excalidraw/excalidraw](https://github.com/excalidraw/excalidraw) `packages/excalidraw`, at the same relative paths, in upstream's formatting (excluded from `vp fmt` and `vp lint` in the root `vite.config.ts`).

| What                                                            | Version                                       |
| --------------------------------------------------------------- | --------------------------------------------- |
| Vendored commit                                                 | `2c3dcc06ec807e81ab9437eceb1a8f7a3c590743`    |
| `@excalidraw/common`, `@excalidraw/math`, `@excalidraw/element` | `0.18.0-2c3dcc0` (npm `next` for that commit) |

Bump all of them together: the engine packages and `src/core` must come from the same commit.

## What changed from upstream

Mechanical, everywhere:

- `React.PointerEvent` / `KeyboardEvent` / `MouseEvent` / `DragEvent` / `TouchEvent` → the DOM event types; `event.nativeEvent` → `event`.
- `React.ReactNode` / `JSX.Element` in `types.ts` → `UINode` (`unknown`).
- `flushSync` from `react-dom` → `flushSync` from `reactUtils.ts`.
- `PanelComponent` and `icon` removed from every action (`actions/*`). The `.tsx` files without JSX left became `.ts`.

Removed, the host brings them (see the README's "Bring your own"):

- `fonts/<Family>/` (the woff2 files): the `fonts` prop. The docs app's set is in `apps/web/src/demos/excalidraw/fonts`.
- `locales/*.json` but `en.json`, and `percentages.json`: the `locales` prop.
- `subset/` (harfbuzz and woff2 wasm) and `workers.ts`: `setFontSubsetter`.
- The icons (upstream `components/icons.tsx`).

## Syncing

```bash
git -C <excalidraw> diff 2c3dcc0..<new> -- packages/excalidraw
```

Apply each hunk to the same path under `src/core` (`.tsx` → `.ts` where the file was renamed). For `components/App.tsx`, the class body maps one to one; JSX hunks go to the Solid layer (`src/components`, `src/solid`). Then bump the three `@excalidraw/*` dependencies to `0.18.0-<new>` and update the table above.
